## The word

**tabpocalypse** — 12 characters.

The whole internet, distilled: forty-seven tabs you swore you'd read later, still open, still judging you. Every rabbit hole, every "just one more video", every article saved for a future self who will never arrive — all of it, living in your tab bar until the browser gives up.

## Run it

```sh
npx tsx main.ts
```

Or with an explicit output directory:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out npx tsx main.ts
```

The program writes the single word to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`), then re-reads the file to verify
the content matches exactly.
